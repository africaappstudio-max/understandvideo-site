Help.

Per-app details. The installer already connects most of these for you.

Re-run or activate later

Follow the How to install steps again (Mac: paste the one line in Terminal; Windows: run the installer). It asks for your license key. Your license works on up to 3 of your computers.

Claude Desktop
  1. Run the installer (it connects Claude Desktop for you).
  2. Fully quit Claude Desktop (Mac: Cmd+Q; Windows: right-click its tray icon, Quit) and open it again.
  3. Start a new chat and type: Understand this video for me: ~/Desktop/My Video.mp4. Click Allow if Claude asks.

Check it works: Settings, Developer shows "Understand This Video" as running.

Cursor
  1. Run the installer, then restart Cursor.
  2. Open Cursor Settings (Mac: Cmd+Shift+J; Windows: Ctrl+Shift+J) and click Tools & MCP.
  3. In the Agent chat type: Understand this video for me: /path/to/video.mp4.

Check it works: "Understand This Video" has a green dot.

Claude Code

The installer connects it if Claude Code is installed. Start claude and ask about a video. Check with claude mcp list: it shows as Connected.

Grok Bot

Grok Bot works on its own cloud computer, so you ask the Bot to set the plugin up on its computer. It then works on video files you give the Bot.

  1. Open a chat with your Bot.
  2. Send the setup message from the Grok Bot guide (copy and paste, one message).
  3. Enter your license key in the secure box the Bot shows. Never type it in the chat.

Check it works: ask "Which tools does Understand This Video have?"

Windsurf, Gemini CLI

The installer connects them if they are installed. Restart the app afterwards.

VS Code, LM Studio, Cline

Run the installer first, then follow the short steps for your app in the full guide.

If something goes wrong
  • "License error": run the installer again and re-enter the key exactly as in your email.
  • "ffmpeg not found": run the installer again, it adds it.
  • A video link is rejected: the plugin only works on video files on your computer. Download or export the video first.
  • A log of the install is saved in the .video-context folder in your home folder (install.log).
  • Still stuck? Email video@shipmonthly.com and attach that file.
